## [0.1.0] - 2026-07-25

### Added

- MCP tools for every operation in QuickFile's REST API v2 Swagger document.
- Personal bearer-token authentication.
- Typed path, query, body, and multipart parameters generated from Swagger.
- Read-only, idempotent, and destructive MCP annotations.
- Mutation confirmation gates, rate-limit metadata, response-size limits, and
  secret-safe errors.
- Mock contract tests and live unauthenticated endpoint checks.
